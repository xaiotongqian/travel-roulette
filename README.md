# 旅行抽签 · Travel Roulette

不知道去哪玩时，按「市内 / 省内 / 国内」随机抽一个目的地。支持标记已去、好感加权、预算与时长筛选。纯前端，数据存在浏览器本地。

## 最近优化

- 快捷预设：周末穷游 / 省内短途 / 国内长假
- 抽中历史（最近 20 次），可「再去」「加心」
- 「就去这儿」自动复制分享文案；结果页也可手动复制
- 地点库：标签筛选、批量标记已去、星级好感
- 无候选时的空状态引导；主按钮更醒目；亮/暗色切换
- 默认明亮旅行浅色（砂白/天蓝/暖橙）；暗色仍可右上角切换
- 视觉层次、转盘光晕与结果卡片仪式感加强
- 抽中后展示详情：简介 / 美食 / 美景 / 文化 / 路径 / 贴士
- 高德 / 百度 / Google 地图搜索链接

## 怎么打开

### 方法一：直接打开（最简单）

用浏览器打开本目录下的 `index.html` 即可：

- macOS：右键 → 打开方式 → Chrome / Safari / Firefox  
- 或把 `index.html` 拖进浏览器窗口  

### 方法二：本地小服务器（推荐，避免个别浏览器限制本地脚本）

在项目目录执行：

```bash
cd /workspace/travel-roulette
python3 -m http.server 8765
```

然后浏览器访问：http://127.0.0.1:8765/

手机同一 Wi‑Fi 下可访问电脑的局域网 IP（如 `http://192.168.x.x:8765/`）。

## 功能一览

| 功能 | 说明 |
|------|------|
| 范围切换 | 市内 / 省内 / 隔壁省 / 国内 |
| 出行目的 | 不限 / 散心闲逛 / 文化熏陶 / 户外运动 / 美食（可多选） |
| 行车距离 | 不限 / 自定义 km（快捷 500/800）；字段 driveKm 为估算行车距离 |
| 转盘抽签 | 带旋转动画与结果卡片 |
| 排除已去 | 可勾选抽签时不抽已标记地点 |
| 好感加权 | 地点库里用 + / − 调权重 |
| 预算档 | 穷游 / 适中 / 奢一点 |
| 出行时长 | 一日 / 周末 / 长假 |
| 季节月份 | 春夏秋冬或指定月份 |
| 再抽 / 就去这儿 | 确认后记入行程意向 |
| 足迹 | 覆盖率、区域芯片、已去列表 |
| 自定义地点 | 自行添加名称、范围、标签等 |
| 导出/导入 | JSON 备份与恢复 |

## 改默认地点

编辑 `data.js`：

- `homeCity`：提示文案里的默认城市  
- `places`：增删改地点；字段见文件顶部注释  

用户在页面里「添加」的地点、已去标记、权重和行程意向存在 `localStorage`（键名 `travel-roulette-v1`），**不会**被改 `data.js` 清掉。换电脑前请到「备份」页导出 JSON。

## 说明

- 默认示例：市内≈上海、省内≈广东、国内=各地热门目的地。  
- 无后端、无账号；清空浏览器站点数据会丢失本地记录（可先导出）。  

## 地点详情字段

抽中地点后，结果卡片下方会展示分区详情（无数据则显示占位提示）：

| 字段 | 说明 |
|------|------|
| `intro` | 简介 |
| `food` | 美食推荐（数组） |
| `sights` | 美景/打卡（数组） |
| `culture` | 文化/氛围（数组） |
| `route` | 路径建议（文字） |
| `tips` | 小贴士（数组，可选） |
| `mapQuery` | 地图搜索词（可选，默认用名称） |

地图链接用地点名生成高德 / 百度 / Google 搜索（新标签页打开）。

- 路径建议按自驾；地图优先「百度驾车导航」（深圳出发）
